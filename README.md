# Сайт Nextezy

Гайды по Path of Exile.

- `index.html` главная со списком гайдов
- `pconc/` гайд «Отскакивающая ядовитая смесь на Следопыте»
  - `index.html` текст гайда
  - `data.js` камни, вещи и флаконы по этапам (правятся здесь, обновляются и во вкладках, и в карточках в тексте)
  - `img/` картинки
- `assets/` общее для всех гайдов: оформление (`style.css`), логика (`app.js`), мини-вики (`wiki.js`), шрифт Onest
